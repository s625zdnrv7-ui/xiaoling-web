# XiaoLing V2 starter
This is a UI prototype, not a connected AI.
On iPhone, create a PUBLIC GitHub repository `xiaoling-web`. Upload ONLY index.html and README.md, never personal memory or API keys. In Settings > Pages choose Deploy from a branch, main, /(root). Open the Pages URL in Safari and use Share > Add to Home Screen.
Wake-word detection requires a manual tap and a supported browser; it does not listen in the background. Memory is stored only in browser localStorage; keep the original JSON in Files. Cloud/Local switching requires a future authenticated backend with secrets stored server-side.
